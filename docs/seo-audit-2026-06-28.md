# SEO & Technical Audit — sohadot.com (2026-06-28)

## Issues Identified via Google Search Console

### 1. Structured Data Error — Invalid object type for `creator` field
- **Page**: `https://sohadot.com/dropping.html`
- **First detected**: 18/06/2026
- **Root cause**: The `Dataset` schema used `"creator": { "@id": "..." }` — a bare `@id` reference with no `@type`. Google's Rich Results parser cannot resolve it because the `Organization` entity was not defined in the same `@graph`.
- **Fix applied**: Added full `Organization` and `WebSite` entities to the `@graph` in `dropping.html`. Changed `creator` to `{ "@type": "Organization", "@id": "...", "name": "Sohadot.com", "url": "..." }`. Updated `dateModified` to 2026-06-28.
